# Hi, I'm Hiriyan 👋

> **"Software should be a quiet bridge between a problem and its solution."**

I don't just write code; I build systems that solve real-world friction. I believe that discipline beats talent every single day and that the best tools are the ones that feel invisible to the people using them. 

My focus is on creating high-impact software for my community—ranging from educational logic to local business infrastructure—while maintaining a standard of "building in public."

- **Intentional Design:** Logic over syntax.
- **Local Impact:** Solving the problems right in front of me.
- **Consistency:** Showing up until the system is seamless.
